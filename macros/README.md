# contiguous-tree-macros

Procedural macros for [contiguous-tree](https://crates.io/crates/contiguous-tree):
`tree_schema!` generates typed tree families, and `#[derive(TreeCursor)]`
delegates cursor operations through a wrapper. Both are reexported by
`contiguous-tree`; applications normally depend on that crate.

See the [macro documentation](https://docs.rs/contiguous-tree-macros) for schema
syntax and generated types.
